🎓 Faculty Selection System

A Streamlit web application that allows students to select their preferred faculty for each subject. The system also provides an admin dashboard with real-time analytics and visual charts showing top faculty choices per subject.

🧩 Features

✅ Student login using registration number
✅ Year-wise subject and faculty selection
✅ Automatic data storage in CSV format
✅ Admin dashboard to view all student choices
✅ Visual charts for top faculty preferences per subject

🏗️ Tech Stack

Frontend & Backend: Streamlit

Database: CSV (Pandas DataFrame based)

Visualization: Matplotlib


⚙️ Installation & Run

Step 1: Clone this repository

git clone https://github.com/irfan95sayyad/Faculty-Selection-System.git
cd Faculty Dash Board

Step 2: Install dependencies

pip install -r requirements.txt


Step 3: Run the app

streamlit run app.py
